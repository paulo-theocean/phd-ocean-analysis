# PhD Ocean Analysis

First draft Python package for oceanographic and atmospheric analysis routines used in PhD research.

## Current modules

- Exploratory data analysis
- 1D yearly statistics
- 2D spatial statistics
- Seasonal and monthly maps
- Scalar and vector plotting utilities

## Installation

```bash
conda env update -f environment.yml --prune
conda activate phd-ocean
python -m pip install -e .
